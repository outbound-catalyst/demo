# Event Playbook: agent entry point

This repo is a playbook for working one event to build pipeline. It is written for any coding agent.

- First time here (no `config/` folder): read INSTALL.md and follow it.
- To run the playbook for an event: read `.claude/skills/event-playbook/SKILL.md` and follow it.

Rules that always apply:

- Never send, post or connect without the user's explicit approval of the exact text and list.
- Say how many records and which tool before spending any credits, and wait for an OK.
- Lead lists and personal data go in `data/` or the user's own tools, never in git.
- Never ask for API keys in chat.
